# Bitácora AEW

Calendario y registro personal de todos los shows de AEW desde 2019: Dynamite, Collision, Rampage, Dark, Elevation, especiales y pay-per-views.

Se instala como app (PWA): abre la página en Safari, toca **Compartir → Agregar a pantalla de inicio**. Funciona sin conexión y guarda tus marcas solo en tu dispositivo; usa **Respaldo** dentro de la app para exportar o importar una copia.

Los episodios semanales se generan con el horario regular de cada programa; las fechas de PPV y especiales vienen de anuncios oficiales y prensa especializada. Es un proyecto de fan, sin relación oficial con All Elite Wrestling.
